只给朋友玩的小网站。neal.fun 那种味道：深色、轻快、文案像朋友说话。

## 就一个地址

对外的地址只有一个，电脑、手机、4G/5G 流量、别人家 WiFi 都用它：

```
https://sit-democrats-tenant-suggestion.trycloudflare.com
```

- 地址写在 `tunnel-url.txt`，同时自动写进桌面的「数字炸弹」快捷方式和桌面那份指南 —— 三处永远同一个。
- **重复双击 `在线.bat` 不会换地址**：脚本看隧道还活着就沿用（`tunnel.log` 里那个域名），只有隧道真被关掉重开才会换新的。
- 换地址了会自动更新上面那三处；把新地址重新发给朋友就行。
- 脚本会先试 https（地址栏有小锁），连不上才退回 http 形式，不用自己改协议。
- 免费隧道拿不到固定域名；想焊死成 `www.xxx.com` 要买域名（一年几十块）接到 Cloudflare 上，说一声就配。

自己调试用的内部地址（不对外，朋友不用管）：

- `http://localhost` / `http://127.0.0.1:5080` —— 本机；80 端口被占时只有后者能用
- `http://192.168.1.7`（以控制台打印为准）—— 同一个 WiFi 下直连，不经过隧道，最快

## 速度（为手机流量专门做过的）

这台机器到 Cloudflare 的线路要绕美国（运营商路由决定，改不了），一个来回 200ms 起步，
所以优化思路就一条：**能不跑的往返就不跑，能不传的字节就不传**。

- **传输压缩**：HTML/CSS/JS/JSON 全部 Brotli（老浏览器退 gzip），总共约 126KB 的页面资源压到 40KB 左右。
- **样式内联**：`style.css` 在启动时直接嵌进 `index.html`（源文件还是 css/style.css，改了自动重新嵌），
  首屏少等一个来回，实测第一次打开快了约 1 秒。
- **静态资源缓存一年**：css/js 的引用都带 `?v=版本号`，版本一变地址就变，所以浏览器可以放心存。
  第二次打开基本一个字节都不用下载，实测 1.4s → 0.65s。
- **进站合并请求**：`/api/boot` 一次带回「门禁状态 + 我是谁」，替代原来的 `gate/state` + `me` 两次。
- **版本号内联**：页面里带 `<meta name="nb-version">`，进站比对版本不再单独请求 `version.json`（每 45 秒才问一次）。
- **头像瘦身**：自画头像存 256×256（显示尺寸根本用不到 512），上传和加载都小了一个量级；
  别人的头像缓存 10 分钟，自己换头像时前端会带 `?t=` 绕开缓存。
- **对局走 WebSocket 长连接**：猜一次 50ms 上下有回应，不按 HTTP 每次重新握手算。

## 想要加密（可选，默认不开）

改 `appsettings.json` 里的 `"Https": true` 并重启，网站会多开一个 `https://…:5443` 入口
（需要先跑 `make-cert.ps1` 签证书）。两个端口同时可用，http 不会被赶走。

- `make-cert.ps1`：建本地根 CA + 签服务器证书（SAN 覆盖 localhost / 机器名 / 当前局域网 IP），产物在 `certs/`。
- **换了 WiFi、IP 变了**：跑一次 `powershell -ExecutionPolicy Bypass -File make-cert.ps1 -Force`，重启服务即可。
- 朋友手机用 https 入口的话，要装一次根证书（`https://…:5443/root-ca.cer`），iPhone 装完还要去证书信任设置里打开开关。
- 故意不发 HSTS：一旦发了，浏览器会把 http 地址强行升级成 https（那边没服务），朋友反而打不开。局域网小站不值这个风险。

## 访问密码（1.6.0 起默认关闭）

门口现在**不设密码**：`appsettings.json` 里的 `AccessPassword` 留空，全世界点开网址就能玩。

想恢复成「只给朋友玩」：把那一行填上（建议 4 位以上）再重启服务，密码页会自动回来。

```json
"AccessPassword": ""
```

填了之后的规则：改这一行（或设环境变量 `NB_ACCESS_PASSWORD`，优先级更高）重启生效。大小写都认（`sucne` 和 `SUCNE` 一样）。同一个 IP 连错 5 次，歇 10 分钟才能再试；每分钟最多试 12 次（限流兜底）。密码对了会发一个 30 天有效的签名 Cookie（HttpOnly），Cookie 里带着口令指纹，换了口令旧票自动作废。

## 后台（只有你能进）

地址：`http://localhost/admin`（或 `http://你的IP/admin`）。站内没有任何入口，`robots.txt` 和响应头都写了禁止收录。

- **密钥**：第一次启动自动生成在项目根目录的 `admin.key` 文件里（已加 .gitignore）。想换成自己的：设环境变量 `NB_ADMIN_KEY`（至少 8 位）或删掉 `admin.key` 重启重新生成。
- **能看**：账号数、积分总和、今天新来、自画头像数、房间列表（房号/状态/玩家，**不含炸弹数字**）、账号列表（名字/积分/头像类型/注册和最后登录时间）。**看不到**：密码哈希、画像原图、IP。
- **能做**：±10 分、把积分设成任意值、删号（删号会自动把人从牌桌上请下去）。
- **防泄露设计**：后台接口没票一律返回 404（外面探测不到「这里有个后台」）；登录 5 次错锁 15 分钟 + 每 5 分钟最多 8 次；票 2 小时过期、HttpOnly + Secure + SameSite=Strict，换密钥全废；页面 `noindex`。

## 这次加的安全措施一览

- **入口**：默认 http（局域网随便进），`"Https": true` 时多开一个加密入口，互不打扰；不发 HSTS（原因见上）。
- **Cookie**：登录/门禁/后台三类 Cookie 全部 `HttpOnly`，走 https 自动带 `Secure`，后台票 `SameSite=Strict`。
- **响应头**：CSP（脚本只许本站、连接只许本站和 ws/wss）、`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: no-referrer`、`Permissions-Policy`、`X-Robots-Tag: noindex`；不对外暴露 `Server` 头。
- **限流**：门禁 12 次/分、注册登录 20 次/分、后台登录 8 次/5 分钟，按 IP 独立计数。
- **密码哈希**：PBKDF2-SHA256 迭代 60 万 + 随机盐；老账号下次登录自动升级，不用改密码。
- **登录接口**：名字不存在也照样算一次哈希，时间上区分不出哪些名字真的存在。
- **自画头像**：服务端校验必须是方形 PNG、边长 ≤1024、体积 ≤400KB，别的东西塞不进来。
- **出错不打烊也不漏底**：异常只回一句「刚刚有点卡，再来一次？」，堆栈只进控制台。

## 玩法 / 规则速记

- 注册送 100 分；踩炸弹 -5，没踩的 +10，缩范围缩得最多的再 +5；积分最低停在 0。
- 房间 2~8 人，范围跨度最多 10000，超出会说「范围太大啦，收一收」。
- 开房后最多等 1 分钟：凑够人数/满员就开；1 分钟还只有自己，机器人「阿呆/小机灵鬼」进来陪你（它不知道炸弹是几，只在范围中间附近猜，偶尔故意猜偏）。
- 期间随时点「算了，不玩了」回大厅。

## 对话与管理（1.7.0）

- **公屏**在大厅页面底部，走 SignalR 实时广播，只保留最近 80 条的画面（库里全存）。
- **私聊**：顶栏 💬 或好友列表的「聊」。发送走 Hub 的 `SendChat`（校验好友关系、禁言、500 字上限），落 `chats` 表，推给双方；未读数在 `/api/chat/threads` 里。
- **禁言**：管理员对普通玩家设置（管理员动不了平级），公屏和私聊一起拦，被禁言的人输入框直接锁住。
- **踢人**：`RoomManager.Kick` 把人从牌桌上请下去并广播；房间空了也会通知，被踢的人自动回大厅。
- **任命**：只有开发者能改 `users.role`，名单里的人（Owner:Names）天生 dev，改不了。
- 管理面板入口在大厅工具条 🛡️，普通玩家看不见这个按钮。

## 好友 / 站内信 / 金币道具（1.4.0）

### 好友
- 大厅或顶栏的 👥 打开。搜名字（打几个字就有联想）→ 加好友 → 对方在 👥 里点「同意」。
- 在线状态是实时的：SignalR 连着就算在线，关掉浏览器或断网，好友那边几秒内变灰。
- 同一个号开两台设备也算在线；最后一条连接断掉才算下线。
- 数据在 `friendships` / `friend_requests` 表里，删号时会连着清干净。

### 站内信
- 顶栏 ✉️。收件箱 / 发件箱 / 写信三个页签，正文最多 2000 字。
- 有新信时对方的信封会冒红点 + 弹 toast（走 SignalR 推送，不用刷新）。
- 点开即标记已读；收件人和发件人都能删。

### 金币与道具
- 金币独立于积分：**赢一局 +30，踩雷扣 1~100（随机）**，新号送 100。
- 商店三样道具（`Models/Shop.cs` 里一处改价格）：
  - 🛡️ 免死金牌 60：这一把踩雷不扣分
  - 🔍 探测器 40：悄悄告诉你炸弹在左半还是右半，只有自己看得见
  - 💨 金蝉脱壳 30：这一轮跳过，让给下一位
- 使用规则：对局进行中、轮到你、这一把没用过同名道具。用了会广播「谁用了什么」，但探测结果只回给本人。
- 库存在 `inventory` 表；对局里扣道具和扣金币是同一场事务。

## 发新版怎么做

1. 改完 js/css 后，把 `wwwroot/version.json` 里的 `version` 改成新版本号；
2. 同时把 `index.html`（和 `admin/index.html`）引用处的 `?v=x.y.z` 一起改掉（样式是启动时自动内联的，不用额外处理）；
3. 重启服务。朋友那边开着页面的话，45 秒内会弹出「更新到 x.x.x 啦，刷新一下就是新的」，点一下刷新即可（没用 Service Worker，刷新就是最新）。

## 已知的简化（够用，但不追求企业级）

- 默认 http 是明文传输：局域网里有人真要抓包是抓得到的。介意的话开 `Https` 开关。
- 房间状态在内存里：重启服务 = 所有进行中的房间消失（账号和积分在 SQLite 里，不丢）。
- 对局中刷新页面会退出当前房间（下一把再进来就行），没有做断线重连回座。
- 机器人的积分不落库，只是这一局里的数字。
- 限流和门禁的错误计数都在内存里，重启清零。
